# MultiplyGame – Kertolaskukisa

**Pelaa selaimessa: https://kijuku.github.io/MultiplyGame/**

Kertotaulut 2–12 nopeuskisana – kuka laskee nopeimmin? Toimii tietokoneella, tabletilla ja
Chromebookilla ilman asennusta.

Tarkempi ohje: **[PELIOHJE.md](PELIOHJE.md)**

## Pelitavat

| Pelitapa | Tavoite |
|---|---|
| **Pikakisa** | 5 laskua mahdollisimman nopeasti |
| **Sprintti** | 20 laskua mahdollisimman nopeasti |
| **Minuutti** | Montako laskua ratkaiset 60 sekunnissa |
| **Harjoittelu** | Ei kelloa – ruudukko näyttää, mistä vastaus tulee |

- Kirjoita vastaus näppäimistöllä tai ruudun numeronapeilla – vastaus tarkistetaan heti.
- Väärästä vastauksesta ei tule sakkoa. Oikea vastaus näytetään kolmannen yrityksen jälkeen.
- Peli muistaa, mitkä laskut ovat sinulle vaikeita, ja kysyy niitä useammin.
- Kertotauluja voi rajata (esim. vain 6, 7 ja 8).

## Nimimerkki ja kunniataulu

Pelaa omalla **nimimerkillä**. Kunniataulussa ovat jokaisen pelitavan kymmenen parasta, ja
**kertotaulukartta** näyttää, mitkä laskut ovat jo hallussa. Tiedot tallentuvat vain omaan
selaimeen – mitään ei lähetetä minnekään ilman opettajan taulukkoa (alla).

## Opettajalle: tulokset Google Sheetsiin

Opettaja voi kerätä oppilaiden tulokset omaan Google-taulukkoonsa. Oppilaat avaavat pelin
opettajan antamalla linkillä:

```
https://kijuku.github.io/MultiplyGame/?taulukko=<opettajan taulukkosovelluksen osoite>
```

Tulosnäytölle tulee silloin **Lähetä opettajalle** -nappi, ja oppilas kirjoittaa kerran
**luokkansa** (esim. 5A). Taulukkoon tallentuu vain nimimerkki, luokka ja pelin luvut – ei
nimiä, sähköpostiosoitteita eikä muita henkilötietoja.

Taulukkosovelluksen (Google Apps Script) saa pelin tekijältä.

## Tietoa

- Tehty Unity 6:lla (WebGL). Lähdekoodi ei ole julkinen.
- Peli toimii kokonaan selaimessa, eikä se käytä evästeitä tai seurantaa.
